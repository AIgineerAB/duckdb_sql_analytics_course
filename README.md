# SQL for data analytics with duckdb course

In this course, you'll dive into fundamental SQL including

- querying
- filtering
- aggregations
- joins
- CTEs
- connecting to Python

For this you will be using the following tools:

- duckdb
- duckdb CLI
- duckdb ui
- python
- bash
- git
- github

| **Week** | **Content**                                               | **Lectures** | **Exercise** |
| -------- | --------------------------------------------------------- | ------------ | ------------ |

| 2        | CRUD, conditionals, sorting, functions, grouping, strings | 06-08        | 1            |
| 3        | temporal data, check, set operations                      | 09-11        | 2            |
| 4        | joins, subquery, views, CTE                               | 12-15        | 3, lab       |
| 5        | window functions, python & duckdb                         | 16-19        | lab          |
| 6        | macros, sql injection                                     | 20-21        | lab          |
