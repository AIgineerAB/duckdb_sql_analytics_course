# SQL for data analytics with duckdb course

In this course, you'll dive into fundamental SQL including

- querying
- filtering
- aggregations
- joins
- CTEs
- connecting to Python

For this you will be using the following tools:

- duckdb
- duckdb CLI
- duckdb ui
- python
- bash
- git
- github

| 2        | CRUD, conditionals, sorting, functions, grouping, strings | 06-08        | 1            |

| 4        | joins, subquery, python and duckdb                        | 12-13, 17-18 | 3, lab       |
